# Vendored modules against diffusers 0.41.0 (LANE-149)

One row per vendored `.py` file under `families/<family>/vendor/` (51 files, 17 of them `__init__.py`).
This table is LANE-150's retirement list: every `shipped` and `partial` row is retired there (the user's
word 2026-10-10), and every `none` row stays vendored with its reason in the family's vendor README.

- `verdict`: `shipped` = diffusers 0.41.0 ships an equivalent of the whole module; `partial` = of part of
  it; `none` = no equivalent found.
- `0.41 symbol(s)`: the dotted path of each equivalent; each one resolves by import on the installed
  release (`backend/app/engine/tests/test_vendor_inventory.py` checks it, and checks that the rows match
  the vendored files and their line counts, so a vendor edit or refresh re-opens the row).
- `known differences`: vendored file line vs 0.41.0 file line (`V:` = the vendored file, `U:` = the
  0.41.0 file under `site-packages/diffusers/`). They were found by an AST comparison of every
  same-named class/function (docstrings stripped) plus reading the differing bodies; "identical" means
  the AST matched. They state what parity has to prove; they are not a parity proof.
- A `none` row says what was searched: the 0.41.0 wheel's file list and a grep of the class names
  through `site-packages/diffusers/`, plus an AST name match against the nearest diffusers files.
